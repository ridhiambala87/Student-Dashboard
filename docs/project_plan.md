# Student Performance Analysis

## Objective
Analyze student marks and available student-group attributes
to identify patterns in academic performance.

## Main Questions
1. What are the mean, median, minimum, and maximum marks?
2. Which subject has the highest and lowest average?
3. What percentage of students pass?
4. How are grades distributed?
5. Is attendance associated with marks, if attendance data is available?

## Tools
- Python
- pandas and NumPy
- Matplotlib and Seaborn
- Power BI
- Git and GitHub

## Privacy
Use anonymized IDs and show group-level results only.

## Limitations
Findings describe this dataset only.
Correlation does not establish causation.
Unavailable variables will not be fabricated.
